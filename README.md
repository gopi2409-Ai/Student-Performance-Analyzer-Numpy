# Student Performance Analysis Using NumPy

## About the Project
This project is created using Python and NumPy to analyze student marks in Python, Statistics, and NumPy.

## Concepts Used
- NumPy Arrays
- Student and Subject Averages
- Broadcasting
- Vectorization
- Boolean Indexing
- Advanced Indexing
- Maximum and Minimum Scores

## How to Run
1. Install NumPy using `pip install numpy`
2. Run the program:

   ```bash
   python student_performance.py
   ```
